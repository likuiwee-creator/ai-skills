# 抖音分账明细合并

把抖音来客导出的月度账单 Excel（含「分账明细-正向-团购 / 分账明细-退款-团购 / 分账明细-补偿-团购」三个 sheet）合并成一张干净的对账表。

## 何时使用
- 用户每月从抖音导出账单明细，需要把前 3 个 sheet 合为一张表。
- 关键词：「合并抖音账单」「合并分账明细」「合并这个月抖音账单」+ 一个 .xlsx 文件路径。

## 合并规则（严格按此执行）
1. 以「分账明细-正向-团购」为主表，保留全部原始列。
2. 用「订单编号」匹配「分账明细-退款-团购」：
   - 主表.用户实付金额 += 退款.用户实付金额   ← **两边必须同口径**
   - 主表.提现金额     += 退款.提现金额

   > ⚠️ **禁止**把「订单实收金额」和「用户实付金额」混着加。两者相差平台补贴 / 抖音支付优惠，不是同一个东西。历史踩坑：正向取订单实收 71.00、退款取用户实付 -69.60，全额退款本应得 0，却算出 **1.40**；猩咖 8/09 那笔差额达 12.10。
3. 把「分账明细-补偿-团购」的 订单编号 / 用户实付金额 / 提现金额 三列，追加到主表最下面（其余列留空）。
4. 退款表中未能匹配到主表的订单，兜底追加为新行（来源标记「退款(未匹配主表)」），避免丢数。
5. 末尾追加「数据来源」列用于标识每行来源（正向 / 正向(已并退款) / 补偿 / 退款(未匹配主表)），不改动任何原数据。

## 运行方式
脚本 `merge_douyin_bill.py` 与本文件同目录，依赖 openpyxl（纯 Python，无其他依赖）。

```bash
python "<skill_dir>/merge_douyin_bill.py" "账单路径.xlsx"
# 可选第二个参数指定输出路径，默认输出为 <原名>_合并.xlsx
python "<skill_dir>/merge_douyin_bill.py" "账单路径.xlsx" "输出路径.xlsx"
```

说明：脚本按 sheet 名包含「正向 / 退款 / 补偿」自动识别对应表，列名按精确匹配定位（订单编号 / 订单实收金额 / 提现金额 / 用户实付金额），对列顺序变化有容错。

## 输出与核对
- 产物为单 sheet「合并明细」，行数 = 正向数据行 + 补偿行（+ 未匹配退款行）。
- 跑完打印：主表行数、退款匹配数、补偿追加数、未匹配退款数，以及每笔退款调整明细（订单号 / 订单实收前后值 / 提现前后值），据此向用户汇报。

## 环境
- 优先使用 WorkBuddy 托管 Python：`C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe`
- 若 openpyxl 缺失：在该 Python 下 `python -m pip install openpyxl`（建议在隔离 venv 内安装）。
