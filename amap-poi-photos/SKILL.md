# 高德 POI 实景图批量抓取

按名称列表批量从高德开放平台获取 POI 实景图，输出可直接用于网页 / 小程序的本地图片 + 映射表 + 质量清单。

## 何时使用

- 给一个「地点名称列表」（景区、商场、酒店、门店）批量配真实照片。
- 已有的图太糊，想知道能不能拿到更清晰的来源。
- 关键词：「从高德拿图」「POI 图片」「批量下载景区图」「图片太糊」「配实景图」。

**不适用**：需要精确版权归属的商用图（见下方「版权」）。高德 POI 图著作权属高德或其上传者，正式商用应换授权图 / 免费图库 / UGC。

## 前置条件

1. 用户需在 <https://lbs.amap.com/> 注册并创建 Key，**服务平台必须选「Web服务」**（不是 Web端 JS API、不是 Android/iOS）。
   - 常见错误：用户误选 Android 平台，弹窗会多出 SHA1 / PackageName 字段 —— 提醒改选「Web服务」，那些字段会消失。
2. 个人开发者免费，日调用量足够本项目使用。

## 关键技巧（这是本技能的核心价值，务必照做）

| # | 技巧 | 说明 |
|---|---|---|
| 1 | **`?operate=original` 拿原图** | 高德返回的图片 URL **默认只有 500px 宽缩略图**（放大必糊）。在 URL 后追加 `?operate=original` 即返回原图。实测：500×279 → 1606×898，清晰度提升约 3 倍。**这是最重要的一个点** |
| 2 | **无防盗链** | `store.is.autonavi.com` / `aos-comment.amap.com` / `aos-cdn-image.amap.com` 带不带 Referer 都返回 200，可直接下载或在小程序 `<image>` 中引用。**三个域名均支持 https** |
| 3 | **必须做名称校验过滤** | place/text 会误配近似名称。实测搜「上海科技馆」返回了「上海自然博物馆」。必须传入 `must` 校验关键词（如 `must='科技馆' in poi_name`），不匹配则跳过 |
| 4 | **多策略重试补漏** | 首轮常只能拿到约 75%。对失败的用：① 原名 → ② 去掉「上海/北京」等城市前缀 → ③ 去掉「景区/乐园/观光厅/度假区」等后缀用核心词 → ④ 换同义关键词（如「崇明学宫」→「崇明区博物馆」） |
| 5 | **合理匹配 ≠ 误配** | 「上海中心大厦118层」→ POI「上海之巅观光厅」、「南翔景区」→「南翔古镇」、「前卫村」→「前卫生态村」，这些是同一地点，属合理匹配，不要当错误剔除 |
| 6 | **统一裁切尺寸** | 原图纵横比不一（有超宽 500×216，有竖图 281×500）。居中裁切为 4:3、缩放到 800×600、JPEG q86，页面才整齐 |

## 接口

```
GET https://restapi.amap.com/v3/place/text
    ?key={KEY}&keywords={名称}&city={城市}&offset=20&page=1&extensions=all
```

返回 `pois[].photos[].url`，形如 `http://store.is.autonavi.com/showpic/{id}`。
注意 `extensions=all` 才会返回 photos 字段。

## 运行方式

```bash
python "<skill_dir>/fetch_poi_photos.py" \
  --key <高德Key> \
  --city 上海 \
  --names names.json \
  --out <输出目录> \
  [--width 800] [--quality 86] [--retry]
```

- `--names`：JSON 数组文件 `["上海野生动物园","上海豫园", ...]`，或每行一个名称的 txt。
- 输出：
  - `<out>/images/<名称>.jpg` —— 裁切压缩后的图片
  - `<out>/poi_photos.json` —— 映射表 `{名称: {file, poi, src, size, matched}}`
  - `<out>/poi_photos_report.txt` —— 成功 / 失败 / 疑似误配清单 + 质量分级
- 中断后重跑会自动跳过已成功的条目。

## 校验与交付

跑完后**必须做三件事**：

1. 检查 `poi_photos_report.txt` 里的「疑似误配」列表，逐个判断是误配还是同名异写，误配的单独重抓。
2. 汇总尺寸分布：`<800×600` 的比例若超过 10%，说明原图参数没生效，检查 URL 是否带上了 `?operate=original`。
3. 把失败清单交给用户确认，是继续换关键词试，还是接受无图。

## 版权提醒（每次都要跟用户说）

高德 POI 图片通过官方 API 获取属于合规路径，但**著作权归高德或其上传者**。若产品要**正式上线**（尤其小程序审核），建议替换为：

1. 景区 / 商户官方授权图（对方通常乐意给，有曝光价值）
2. 各地文旅局等官方公开素材
3. 免费商用图库（Unsplash / Pexels / Pixabay）
4. 用户 UGC（长期最优）

替换时只需改数据层里 `img` 字段一个位置，UI 不用动。
