# 同程对账单提取 Skill

## 何时使用
- 用户说「处理同程对账单 / 提取同程账单明细 / 同程对账单去废行改名」并给出 xlsx 路径时。
- 输入：同程导出的对账单（单个 .xlsx，含「对账单详情」sheet）。
- 输出：单 sheet「对账单详情」，已去顶部废行、已改两列名。

## 提取规则（务必遵循）
1. 取「对账单详情」sheet 作为主表（按关键字 `对账单详情` 匹配；只有一个 sheet 时回退用第一个）。
2. **去除顶部 1 行废行**：该文件第 1 行(索引0)通常只有首格写着标题 `对账单详情`、其余列空，
   属无用行，去掉后第 1 行即真表头。
   - 安全判定：仅当该行非空单元格数 ≤ 1 时才去除；若首行已是真表头(含`订单短号`/`实际结算金额`)，
     则不去除以免误删，并提示用户。
3. **表头改名**：
   - `订单短号` → `OTA订单号`
   - `实际结算金额` → `打款金额`
   - 其余列名(主单号 / 子单号 / 产品名称 / 套餐名称 / Sku名称 / 取票人 / 结算模式 /
     旅游日期 / 单价 / 购买份数 / 退款份数 / 币种 / 应结金额 / 退款总额 / 商家红包 /
     订单状态 / 备注 等)原样保留。

## 重要：订单号层级关系（对账须知）
- `OTA订单号`（原`订单短号`）是**主单号级别**的 ID，同程会把一个主单按不同套餐/SKU 拆成多行
  （如：上海科技馆 成人+儿童+婴儿 各一行）。因此 **同一 OTA订单号 可能对应多行**，属正常现象，
  脚本**逐行保留、不做合并/去重**。
- 每行另有独立 `子单号`（每行唯一），若需逐行精确对账可用 `子单号` 作键。
- 脚本会打印「OTA订单号 唯一数 / 重复数」供核对，重复属预期、非错误。
- 打款金额(`实际结算金额`)是**每行的金额**，按主单核对时需对多行求和。

## 运行方式
```bash
# 默认输出 <原名>_订单详情.xlsx
python extract_tongcheng_bill.py "对账单详情.xlsx"

# 指定输出路径
python extract_tongcheng_bill.py "对账单详情.xlsx" -o "输出.xlsx"
```

## 环境
- 依赖纯 Python + openpyxl：`python -m pip install openpyxl`（在隔离 venv 内安装更安全）。
- 无平台依赖，任何装了 Python3 + openpyxl 的机器均可运行，适合直接发给同事或其它 AI 使用。

## 输出与核对
- 产物为单 sheet「对账单详情」，行数 = 源数据行 + 1 表头行（已去 1 废行）。
- 跑完打印：是否去废行、来源 sheet、输出行列数、新表头、改名是否生效、OTA订单号重复提示。
- 与美团/携程/抖音的提取结果对齐：均含 `OTA订单号` + `打款金额` 两列，可直接纳入 OTA 订单核对。
