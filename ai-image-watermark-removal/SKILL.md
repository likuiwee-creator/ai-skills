# AI 生图水印去除（无缝版）

## 何时用
- 本机 **ImageGen/文生图工具产出的图片，右下角固定带一个"AI生成 / WORKBUDD>"水印**（浅灰字 + 小 logo，靠近图像右下角，距右边约 0.3%~0.5% 图宽）。
- 图片要用于**对外发布**（公众号/小红书/知乎/交付客户）时，几乎都需要先去掉。
- 用户提到："不要 AI 生成的字样 / 去水印 / 图上有 AI 标记"。

> 注意：**生图工具本身无法关闭该水印**，只能在生成后做后处理。所以流程上应默认"生图 → 去水印 → 再交付"，不要等用户发现。

## 快速使用
```bash
# 原地去水印（自动备份为 *_raw.png，并输出右下角 2x 自检图）
"D:/Python/python.exe" <SKILL>/scripts/remove_watermark.py --check img1.png img2.png

# 输出到指定目录，不覆盖原图
"D:/Python/python.exe" <SKILL>/scripts/remove_watermark.py --outdir cleaned img1.png

# 水印位置有偏移时微调包围盒
"D:/Python/python.exe" <SKILL>/scripts/remove_watermark.py --offset -20,0 img1.png
```
依赖：Pillow + numpy（Windows 用系统 Python `D:\Python\python.exe`；managed python 常常没有 Pillow）。

## 算法（为什么不用"整块搬运"）
朴素做法是从旁边抠一块贴回去，会在这两种情况翻车：
1. **背景是渐变**（雾气、天空、暗角）→ 贴块亮度和周围不一致，出现可见方块；
2. **右下角本身有摄影投影/暗带**（如人物投影落在右下角）→ 从受光区取块贴到暗区，立刻露馅。

本脚本用三步解决：
1. **盒子的右/下边直接对齐图像边缘** → 这两侧不存在接缝，只需处理左/上边；
2. **可分离插值铺底** `F(x,y) = T(x) + L(y) - T(x0)`（T=上边一行，L=左边一列）
   → 对横向/纵向渐变都能完美贴合，暗带、渐变一并对齐；
3. **像素级颗粒叠加**：从盒子上方取同宽区域做半径 1.8 的高通（只留颗粒、不带结构），
   并按盒子**左侧邻近区**的噪声强度自适应缩放（`min(1, σ_local/σ_tex)`），避免塑料感或噪点过强；
   最后左/上边 30px 宽羽化 + 50% 融合，消除方框边界。

## 关键参数与坑
| 参数 | 默认 | 说明 |
|---|---|---|
| 包围盒 | `0.90W,0.91H → W,H` | 实测水印在 x 92%~99.7% W、y 94%~99.6% H。**右/下务必顶到图像边缘** |
| `--feather` | `2% 图宽` | ⚠ **必须小于"盒子边缘到水印"的距离**，否则羽化区会把水印像素混回来（水印距右/下边极近，所以只能在左/上羽化） |
| 高通半径 | 1.8 | 半径调大（如 4~8）会带进结构纹理 → 角落出现"格纹/网格"感 |
| 颗粒缩放 | 自适应 | 固定 1:1 叠加会让阴影区噪点过强（源区颗粒比阴影区强） |

**自检**：务必看一眼输出的 `*_check.png`（右下角 2x 放大）。合格标准：看不出方框边界、无亮度差、无水印残留。

## 纯色 / 几何图形类图片（logo、图标、按钮）—— 改用镜像重建
`remove_watermark.py` 的插值算法是为**照片**（渐变、纹理）设计的。遇到**扁平纯色 / 几何图形**
（圆角方形 logo、纯色图标、按钮、色块背景）时它会翻车：插值出来的色块与图形边缘不齐，
出现**锯齿、错位、接缝**（实测：绿底圆角方形 logo，插值后右边缘出现明显缺口）。

这类图片请改用 `scripts/mirror_patch.py` —— **从无水印的一侧镜像覆盖**。只要是几何图形，
图形通常左右（或上下）对称，镜像就是**像素级完美**，且天然保住抗锯齿。

```bash
PY="D:/Python/python.exe"; SK="C:/Users/Administrator/.workbuddy/skills/ai-image-watermark-removal"

# 1) 探测对称性（告诉你从哪一侧镜像最干净）
"$PY" "$SK/scripts/mirror_patch.py" probe --img logo.png --box 900,900,1024,1024

# 2) 修补（原地会先备份 *_raw.png）
"$PY" "$SK/scripts/mirror_patch.py" patch --img logo.png --box 900,900,1024,1024 --from left --check chk.png
```

决策流程（先判断图片类型，再选脚本）：
| 图片类型 | 特征 | 用哪个 |
|---|---|---|
| 照片 / 渐变 / 纹理背景 | 水印压在雾、天空、投影、暗角上 | `remove_watermark.py`（插值） |
| 纯色 / 几何图形 / 图标 logo | 背景是纯色或纯白，图形轮廓清晰 | `mirror_patch.py`（镜像） |

要点：
- **先跑 `probe`**，看「左右前景像素数不一致的行数」是否接近 0；接近 0 就说明左右对称，`--from left`（水印在右下）最稳。
- `--box` 一定要**完整盖住水印**，同时**不要盖到图形本体的非对称部分**（例如 logo 里朝右的人的轮廓），否则镜像会把图形镜像坏掉。典型做法：box 只取图形「直角/圆弧边缘 + 留白」那一段（如 `900,900,1024,1024`）。
- 输出仍是 RGB；如果原图是 RGBA（真·透明背景），本脚本按 RGB 处理，透明通道需自行拼回（本机 ImageGen 透明背景常实际输出为白底 RGB，此时无需担心）。
- 修补后**务必看 `--check` 自检图**，确认边缘是平滑的圆弧而不是缺口。

## 常见坑
1. **PIL 的 `ImageDraw` 在 RGBA 图上画半透明色不会混色**，而是把 RGBA 原值写进去；转成 RGB 时 alpha 被丢弃 → 半透明条变成纯白/纯黑不透明块。需要半透明叠加时用 `Image.new("RGBA")` + `alpha_composite()`。
2. **托管 python（`.workbuddy/binaries/python/...`）通常没有 Pillow/numpy** → 图像处理一律走 `D:\Python\python.exe`。
3. 同一批图水印位置可能有 ±10~20px 偏移，用 `--offset` 微调，别改算法。
4. 去水印后若要发文章，记得同时**导出网页用 JPEG**（PNG 常 2MB+，JPEG q90 约 200~330KB）。
