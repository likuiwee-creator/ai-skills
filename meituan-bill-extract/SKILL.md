# 美团账单明细提取

把美团导出的月度账单（通常是 `.xls` 扩展名）中的「订单详情」sheet 单独导出为一张干净的对账表。

## 何时使用
- 用户每次把美团账单里的订单详情单独导出为一张表，用于 OTA 订单核对（按 OTA订单号 + 打款金额 匹配）。
- 关键词：「提取美团账单」「美团订单详情」「导出美团订单明细」+ 一个 .xls/.xlsx 文件路径。

## 提取规则（严格按此执行）
1. 取「订单详情」sheet 作为主表（美团账单常含 总表 / 订单详情 / 调整明细 / 应付金额 / 退款明细 / 商家自促优惠明细 / 商家账户承担优惠明细 / 退款手续费明细 / 公益明细 等多个 sheet，只取 订单详情）。
2. 订单详情 sheet 表头即首行，**无废行，不跳行**。
3. 表头重命名：
   - `美团订单号` → `OTA订单号`
   - `结算金额`   → `打款金额`
4. 其余原始列（商家订单号 / 结算方式 / 产品ID / 产品名称 / 客人姓名 / 张数 / 是否打包 / 主订单号 / 销售时间 / 应付金额 / 退款金额 / 商家承担优惠 / 调账金额 / 退款手续费 / 公益金额 / 技术服务费 / 技术服务费退款 等）全部原样保留，不改动数据。
5. **同订单号多行自动合并（重要）**：美团常把同一订单拆成「正向销售行 + 退款行」两行（退款可能只是部分退，如正向 66.30 / 退款 −50.00）。脚本按 `美团订单号` 聚合：数值列（应付/退款/商家承担优惠/调账/退款手续费/公益/结算金额/技术服务费/技术服务费退款/张数）**求和**得净结算，文本列（客人姓名/产品名称/销售时间等）取「应付金额≠0」的正向行。聚合后每个订单号仅一行，打款金额=净额，金额总额守恒。单周账单通常无重复；多周批量下载账单常见此情况（实测 551 行含 13 个重复订单号，聚合为 538 行）。

## 运行方式
脚本 `extract_meituan_bill.py` 与本文件同目录，依赖 openpyxl（纯 Python），老 .xls 兜底依赖 xlrd。

```bash
python "<skill_dir>/extract_meituan_bill.py" "账单路径.xls"
# 可选第二个参数指定输出路径，默认输出为 <原名>_订单详情.xlsx
python "<skill_dir>/extract_meituan_bill.py" "账单路径.xls" "输出路径.xlsx"
```

## 重要格式说明（踩坑点）
- 美团导出的 `.xls` 多数其实是**被改了扩展名的真 xlsx**（文件头是 `PK` ZIP 签名）。openpyxl 按扩展名 `.xls` 直接打开会报 `InvalidFileException`，脚本已用「读字节 → 若是 ZIP 则转 BytesIO 喂给 openpyxl」绕开，自动兼容，无需手动改扩展名。
- 若遇到真正的老格式 OLE2 `.xls`（文件头 `D0CF11E0`），脚本自动回退用 xlrd 读取。
- 因此：普通美团导出只需 openpyxl；只有极少真 OLE2 老文件才需 `python -m pip install xlrd`。

## 输出与核对
- 产物为单 sheet「订单详情」，行数 = 源订单详情数据行 + 1 表头行。
- 跑完打印：来源 sheet 名、输出行数、输出列数、新表头前几列，据此向用户汇报。

## 对账关系（关键，避免误解"三个子表合起来≠订单详情"）
美团账单是**多 sheet 互相引用**的结构，关系如下：
- **订单详情 = 主表（每行一笔交易明细）**，同一行内含 应付金额 / 退款金额 / 调账金额 / 结算金额(=打款金额) 全部字段。**注意：美团可能把同一订单拆成「正向销售行 + 退款行」两行**（退款可能只是部分退），故"每订单一行"并不绝对；脚本已自动按订单号聚合成单行净结算，输出的订单详情每个订单号仅一行、金额总额守恒。对账只需这一张。
- 应付金额 / 退款明细 / 调整明细 **不是把主表切成三块**，而是三个有交集的"筛选视图"：
  - 应付金额 = 订单详情中 `应付金额>0` 的订单
  - 退款明细 = 订单详情中 `退款金额≠0` 的订单，但**一笔订单可被拆成多行**（分次部分退款）→ 行数 ≠ 退款订单数
  - 调整明细 = `调账金额≠0` 的订单
  - **重叠**：存在"先卖后退"的订单同时出现在 应付金额 与 退款明细 中（实测批量账单约 54 个），故三表行数相加会 > 主表行数，是重复计数而非漏数。
- **金额层面完全勾稽**（列不重叠，各子表只搬对应列）：
  - Σ订单详情.应付金额 = Σ应付金额sheet.应付金额
  - Σ订单详情.退款金额 = Σ退款明细sheet.退款金额
  - Σ订单详情.调账金额 = Σ调整明细sheet.调整结算金额
  - Σ订单详情.结算金额(打款) = Σ应付 + Σ退款 + Σ调账 = Σ总表(按周汇总)的结算金额合计
- 总表 = 按结算周期(周)的汇总，每行一周，合计应等于订单详情打款总额。
- **结论**：对账取订单详情即可，不用拼三个子表；子表仅用于钻取（退款分几次退、某周打款多少）。
